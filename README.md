#Flight Ticket Booking System

## Problem Statement
Booking flight tickets manually can be time-consuming and error-prone for both customers
and service providers. This project aims to develop a flight ticket booking system that
allows users to search for flights, view available options, and book tickets efficiently
while maintaining accurate booking records.

## Objective
The main objective of this project is to design and implement a simple and user-friendly
flight ticket booking system that automates the booking process and improves customer
experience.

## Features
- Search available flights by source, destination, and date
- View flight details such as airline, price, and departure time
- Book flight tickets
- Store booking details
- Basic validation for user input

## System Workflow
1. User enters travel details (source, destination, date)
2. System searches available flights
3. User selects a flight
4. Booking details are validated and stored
5. Ticket booking confirmation is generated
